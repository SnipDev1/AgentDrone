## Block 2: Computer Vision Core (Ядро CV) — Дедлайн: 21:30
- [x] **CV-01: Детекция конструктивных элементов (Фундамент / Стены / Кровля / Окна)**
  * *Верификация:* Выделение контуров, граней, оконных проемов и расчет доверия (`src/cv/feature_extractor.py`).
- [x] **CV-02: Вычисление процента готовности и маппинг в 0% / 50% / 100%**
  * *Верификация:* Соответствие весам Банка (15% фундамент + 40% стены + 30% кровля + 15% контур) (`src/cv/readiness_classifier.py`).
- [x] **CV-03: Классификатор материалов стен (Кирпич / Блок / Брус / Щитовой / Сэндвич)**
  * *Верификация:* Анализ цветовых и текстурных сигнатур на фасадных ракурсах (`src/cv/material_classifier.py`).
- [x] **CV-04: Детекция риска нецелевого использования (Stop-Fraud)**
  * *Верификация:* Флаг подмены материалов (дерево/каркас вместо кирпича) и коммерческий супермаркет на ИЖС (`src/cv/fraud_detector.py`).
- [x] **CV-05: Детекция критических внешних дефектов**
  * *Верификация:* Отсутствие консервации стен зимой, признаки долгостроя, опасные ЛЭП и кроны деревьев (`src/cv/fraud_detector.py`).
- [x] **CV-06: Фотограмметрическая 3D-проекция кадастровых границ (Pinhole + RTK + Yaw/Pitch/Roll + 3м отступ СП 53.13330)**
  * *Верификация:* Честная 3D-проекция поворотных точек WGS84 с учетом ориентации камеры (Gimbal Yaw/Pitch/Roll), высоты полета, калиброванного фокуса, дисторсии объектива (DewarpData) и отсечения точек за камерой для надирных и фасадных снимков (`src/cv/boundary_overlay.py`, `tests/test_cv.py`).
- [x] **CV-07: Селективное маскирование полигона ЗУ (Gatekeeper для 0%) и точная детекция остекления окон vs пустых проемов**
  * *Верификация:* Анализ снимков строго внутри границ кадастрового участка (исключение соседних домов и дорог), строгая дискриминация остекления с рамой vs пустых черновых проемов в стенах, ограничение незакрытого контура до 50% стадии (`tests/test_cv.py`).
