# AgentDrone: Спецификация датасета и командного взаимодействия

## 1. Общие сведения

Проект **AgentDrone** предназначен для обработки и анализа данных аэрофотосъёмки с беспилотных летательных аппаратов (БПЛА DJI) над кадастровыми земельными участками. 

Датасет содержит:
- Высокодетальные ортогональные RGB-снимки (`.JPG`).
- Мультиспектральные снимки в 4 диапазонах (`.TIF` — NIR, RedEdge, Red, Green).
- Высокоточные GNSS/PPK-логи позиционирования (`.obs`, `.nav`, `.bin`).
- Метки срабатывания затвора камеры (`.MRK` с точными координатами центров снимков).

Общий объём текущего набора: **142 файла (~868 МБ)** по **13 кадастровым участкам**.

## 3. Инструкция для членов команды: Быстрый старт

Каждый разработчик или аналитик в команде может получить датасет одним из двух способов:

### Вариант А: Автоматическая загрузка через скрипт (Рекомендуется)

1. Клонируйте репозиторий:
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   cd AgentDrone
   ```

2. Запустите скрипт загрузки:
   ```bash
   python download_disk.py
   ```
   *Скрипт автоматически скачает все файлы с Яндекс Диска в многопоточном режиме, проверит контрольные размеры каждого файла и положит в `dataset/24.09.20206`.*

3. Проверьте корректность загрузки:
   ```bash
   python -m src.dataset
   ```

---

### Вариант Б: Ручная загрузка из Яндекс Диска

1. Перейдите по ссылке: [Яндекс Диск (24.09.20206)](https://disk.yandex.ru/d/_R6xYg1frCGW0w).
2. Скачайте папку целиком или архивом.
3. Распакуйте папку `24.09.20206` в каталог `dataset/` внутри проекта:
   `AgentDrone/dataset/24.09.20206/<папки_с_номерами_участков>`
4. Проверьте валидатором:
   ```bash
   python -m src.dataset
   ```

---

### Вариант В: Хранение датасета на внешнем диске / SSD

Если на системном диске мало места или данные хранятся на сетевом хранилище/внешнем диске:

1. Скопируйте `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
2. Укажите абсолютный или относительный путь к вашей папке:
   ```env
   DATASET_DIR=D:/Datasets/AgentDrone/24.09.20206
   ```
3. Все модули проекта будут автоматически читать датасет по указанному пути.

## 4. Спецификация файлов и форматов

| Формат / Маска | Тип данных | Назначение |
|---|---|---|
| `DJI_*_D.JPG` / `DJI_*_F.JPG` | RGB-фотографии | Ортофотопланы, визуальная детекция объектов, фотограмметрия |
| `DJI_*_MS_NIR.TIF` | Ближний инфракрасный (NIR) | Расчёт вегетационных индексов (NDVI, GNDVI) |
| `DJI_*_MS_RE.TIF` | Красный край (RedEdge) | Анализ хлорофилла и стресса растений |
| `DJI_*_MS_R.TIF` | Красный диапазон (Red) | Мультиспектральный синтез |
| `DJI_*_MS_G.TIF` | Зеленый диапазон (Green) | Мультиспектральный синтез |
| `DJI_*_Timestamp.MRK` | Текстовый маркер затвора | Высокоточные метки времени срабатывания камеры, задержка экспозиции, RTK координаты и погрешности (StdDev) |
| `DJI_*_PPKOBS.obs` | RINEX Observation | Сырые спутниковые наблюдения GNSS с борта дрона для постобработки (PPK) |
| `DJI_*_PPKNAV.nav` | RINEX Navigation | Эфемериды навигационных спутников |
| `DJI_*_PPKRAW.bin` | Raw Binary GNSS | Бинарные телеметрические данные приёмника дрона |
| `*.txt` | Текстовые заметки | Операторские пояснения к участку |

## 5. Использование данных в Python коде

Для исключения хардкода путей в скриптах команды используйте готовый интерфейс из `src.dataset`:

### Пример 1: Итерация по кадастровым участкам и получение снимков

```python
from src.dataset import DroneDataset

# Инициализация (автоматически находит папку dataset/ или берёт из .env)
ds = DroneDataset()

print(f"Доступен ли датасет: {ds.is_available()}")
print(f"Список кадастровых участков: {ds.list_plots()}")

# Получаем данные конкретного участка:
plot = ds.get_plot("5407055001178")

print(f"Кадастровый номер: {plot.plot_id}")
print(f"RGB снимков: {len(plot.rgb_images)}")
print(f"Файлов PPK/MRK: {len(plot.mrk_files)} MRK, {len(plot.ppk_obs)} OBS")

# Пути к файлам снимков (объекты pathlib.Path):
for img_path in plot.rgb_images:
    print("RGB снимок:", img_path)
```

### Пример 2: Работа с мультиспектральными снимками

```python
from src.dataset import DroneDataset

ds = DroneDataset()
# Участок с мультиспектральной съёмкой:
plot = ds.get_plot("54191646033847")

nir_bands = plot.multispectral_images['NIR']
re_bands = plot.multispectral_images['RE']
r_bands = plot.multispectral_images['R']
g_bands = plot.multispectral_images['G']

print(f"Каналы: NIR={len(nir_bands)}, RE={len(re_bands)}, R={len(r_bands)}, G={len(g_bands)}")
```

## 6. Валидация датасета

Для проверки целостности файлов и вывода сводки предусмотрена встроенная команда:

```bash
python -m src.dataset
```

Пример вывода:
```text

============================================================

Status:               OK

Total size:           867.70 MB
RGB photos (.JPG):    79
Multispectral (.TIF): 12
MRK timestamps:       14
```

## 7. Правила работы с Git для участников команды

1. **Никогда не добавлять тяжелые файлы данных в коммиты.** Папки `dataset/`, `data/`, `*.obs`, `*.part`, архивные и служебные файлы внесены в `.gitignore`.
2. Файл `.env` является локальным и **не коммитится** в репозиторий.
3. Все общие конфигурации и примеры переменных документируются в `.env.example`.
4. В коде запрещено использовать абсолютные пути вроде `C:/Users/...` или `E:/...`. Все пути должны разрешаться через `src.config.DATASET_ROOT` или `DroneDataset()`.
